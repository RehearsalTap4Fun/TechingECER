# 路线图

当前版本已可用于日常教研工作：8 个模块的增删查改、ECERS 计分、《指南》目标关联、文档上传与内容自动分类都已跑通。以下是按价值排序的后续方向。

## 已完成

- **从计划文档一键建专题**（v0.4）
  解析教研计划文档的章节结构，抽出背景、理论支撑、四类目标、主题模块与三类预期成果填进表单供核对。按表头关键词匹配而非固定编号，结构不同的文档降级处理并标出需手填的部分。

- **教研专题层级**（v0.3）
  专题 / 小课题 / 教师培养计划 → 月度主题模块 → 教研活动 → 课例实践。含四类教研目标、三类预期成果与逐条对账，教研活动页直接展示所属专题目标。

- **文档上传与自动分类**（v0.2）
  支持 Word / PPT / Excel / PDF / 文本，按正文内容判定分类、领域、年龄班与标签，展示判定依据供人工复核，正文进入全文检索。提供 `npm run import` 批量导入历史资料。


## 近期

- **导出与打印**
  教案导出 Word / PDF、教研纪要一键打印、ECERS 评估生成园所质量报告。
  页面已预留 `.no-print` 类，打印时会隐藏导航和操作按钮，但还需要专门的打印样式和导出管线。

- **幼儿成长档案页**
  目前观察记录只能按幼儿筛选列表。应该有一个 `/children/[id]` 页面，把某个幼儿的全部观察记录、家园沟通、《指南》各领域目标覆盖情况汇总成一页，家长会时直接调出来用。

- **教案按目标反查**
  数据已经存了（`lessons.goal_ids`），但还没有"点开某条发展目标 → 看有哪些活动覆盖了它"的入口。这是教研主任检查课程结构是否有盲区时最需要的视图。

## 中期

- **学期课程计划**
  教研已经有了专题层级，课程侧还没有：学期主题 → 周计划 → 日活动，并自动核对五大领域配比是否均衡。可复用 `research_topics` 的组织思路。



- **登录与权限**
  当前版本没有任何认证，只适合可信内网。若要多园区共用，至少需要区分教师 / 教研员 / 园长三种角色，并限制幼儿个人信息的可见范围。

- **教师成长档案**
  把某位教师的听评课记录、教研发言、公开课按时间线汇总，用于职称评定和园本培训的依据。

- **数据备份**
  目前备份靠手动拷贝 `data/` 目录。应该加一个定时导出的脚本，并支持导出为 Excel 供园所存档。

## 长期 / 待讨论

- **AI 辅助**
  基于已有的教案库和观察记录，辅助生成活动设计初稿、把教师的口语化观察整理成三段式记录、从多次 ECERS 评估中提炼改进建议。也可以替换现在的词表分类器以提升准确率——`classify()` 的签名 `(fileName, text) => Classification` 就是为了让这一步可以整体替换。

  但需要先确认园所对幼儿数据出境的接受度：当前架构下所有数据不出本机，接入外部模型会打破这一点。若要做，建议先支持本地模型或给出"仅上传脱敏摘要"的选项。

- **多园区 / 集团版**
  跨园所的横向质量对比、教研资源共享。这需要从 SQLite 迁移到 Postgres，并重新设计数据隔离，是一次架构级改动，不应过早开始。

## 明确不做

- **不把 ECERS-3 手册原文录入系统**。评分指标受版权保护，系统只提供条目框架，实际评分必须由受过训练的评估者对照正式手册进行。
- **不做家长端 App**。家园共育模块的定位是园所内部台账，不是家长直接使用的产品。
